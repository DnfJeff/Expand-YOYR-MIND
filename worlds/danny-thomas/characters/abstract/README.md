# Abstract Character Archetypes

Reusable character prototypes for the Danny Thomas Show world. Each YAML file defines an archetype with default traits, needs, and behavioral tendencies that concrete characters inherit from.

These are the _abstract base classes_ of the character system — an entertainer, a patriarch, a homemaker, a sidekick, a comedy-legend, a bridge-character, etc. Concrete characters (Danny, Louise, Uncle Tonoose) reference these as their foundation and override or extend as needed.
