# All Souls Church

Mayberry's spiritual anchor and its most reliable competition venue.

Sunday service brings the whole town together in a way that even Floyd's can't. The church is where Mayberry's values get spoken out loud — the same values Andy practices silently all week. The sermon confirms what the porch conversations already established.

But the real action is in the [fellowship hall](fellowship-hall/) downstairs. Church suppers, fundraisers, talent shows, and the annual bake-off happen here. And every bake-off inevitably becomes a Bee-vs-Clara showdown that the entire town pretends not to be watching while watching intensely.

The church functions as a **community synchronization point** — the one time per week when everyone is in the same room hearing the same words. In system terms, it's where Mayberry's `WORLD.yml` values get explicitly stated rather than implicitly inherited.
