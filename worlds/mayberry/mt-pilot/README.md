# Mt. Pilot

**The "big city" next door** — Mayberry's contrast and pressure release.

Mt. Pilot is the county seat, about thirty minutes from Mayberry. It has things Mayberry doesn't: a movie theater, a diner that serves after 8 PM, places where you can get in trouble. For Mayberry residents, going to Mt. Pilot is an event — it represents the wider world.

Andy goes there for county business. Barney goes there for dates he describes as more exciting than they actually are. The Darlings and Ernest T. Bass come from the mountains beyond Mt. Pilot.

In system terms, Mt. Pilot is a **boundary zone**. It's the edge of Mayberry's world — the place where Mayberry's gentle tone starts to dilute. The `tone` property here doesn't fully inherit from Mayberry's WORLD.yml; it overrides toward `neutral`, making it a space where different social rules can apply.

This is a Tardis-pattern room: the folder seems small (not many files) but represents a large conceptual space that the LLM can expand as needed.
