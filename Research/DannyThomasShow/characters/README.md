## The Visitor System

Unlike Mayberry's fixed cast, the Danny Thomas Show runs on a **visitor pattern**. Characters arrive, disrupt the equilibrium, create complications, and the family adapts. Uncle Tonoose is the ultimate example — his arrivals are seismic events that rearrange the household.

```
Visitor arrives → Apartment disrupted → Danny's plans derailed
→ Comedy of obligation → Resolution through love → Visitor leaves
→ Apartment returns to baseline → Next visitor arrives
```

This is a fundamentally different rhythm than Mayberry, where the same people circulate through the same spaces. Danny's world has a **fixed home + rotating cast** architecture.
