# Research

Working MOOLLM simulations built on Eval Incarnate principles. Each subfolder is a complete living world — directories are rooms, YAML files are objects, characters have inner lives.

## Worlds

- **[Mayberry/](Mayberry/)** — _The Andy Griffith Show_ as a centripetal world. Everything pulls inward toward community consensus.
- **[DannyThomasShow/](DannyThomasShow/)** — _Make Room for Daddy_ as a centrifugal world. Fixed home, rotating visitors, the performance/private boundary.

Both share the same structural patterns: `ROOM.yml` per folder, `CARD.yml` advertisements at key locations, character profiles with needs and traits, and property cascading through directory delegation.
