# Abstract Character Archetypes

Reusable character prototypes for the Mayberry world. Each YAML file defines an archetype with default traits, needs, and behavioral tendencies that concrete characters inherit from.

These are the _abstract base classes_ of the character system — a small-town-lawman, a homemaker, a community-pillar, a chaos-agent, a comic-hero, a romantic-lead, a wildcard, etc. Concrete characters (Andy, Barney, Aunt Bee, Ernest T. Bass) reference these as their foundation and override or extend as needed.
