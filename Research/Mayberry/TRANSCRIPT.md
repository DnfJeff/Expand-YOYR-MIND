# Mayberry Simulation Transcript

> **Persistence tier:** Narrative (read-mostly)
> **Purpose:** Human-readable narrative of what happened during simulation — the "episode"
> **Format:** Prose, dialogue, stage directions — written as the simulation runs

---

## Transcript Format

The transcript reads like a teleplay:

```
## Episode: [title]
### Scene 1 — [Location Name]

*[Stage direction describing the setting and who is present]*

**CHARACTER_NAME:** "Dialogue as spoken by the character."

*[Action or reaction description]*

**ANOTHER_CHARACTER:** "Response dialogue."

> [Narrator note or simulation context, if needed]

---

### Scene 2 — [Location Name]
...
```

---

## Guidelines

- Dialogue should match each character's voice (see CHARACTER.yml `dialogue_style`)
- Stage directions use *italics*
- Character names in **bold** before dialogue
- Scene breaks use `---` between scenes
- Each scene names its location (matches ROOM.yml `room.name`)
- Narrator notes in `> blockquotes` — used sparingly
