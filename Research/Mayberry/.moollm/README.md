# .moollm — Engine Configuration

MOOLLM runtime configuration for the Mayberry simulation.

| File | Purpose |
|------|---------|
| `config.yml` | Bootstrap configuration — reading order, cold/warm start settings |
| `prompt.yml` | LLM system prompt template — rules for character behavior, ad evaluation, turn structure |
| `state.yml` | Warm-start state — current epoch, tick count, character locations |
