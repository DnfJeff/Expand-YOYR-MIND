# Wally's Garage Bay

Goober's real office — the one place where he's the smartest person in the room.

A hydraulic lift, tool chests the size of refrigerators, and parts hung on pegboard walls in an organization system only Goober understands. A bare bulb swings from a cord that's been retaped four times. The radio plays the same station as Floyd's.

In the garage bay, Goober is a different person. Focused. Competent. Precise. He can diagnose a knock by ear, rebuild a transmission blindfolded, and explain what's wrong in terms the car owner can understand. This is domain-specific intelligence — genuine expertise that has no correlation with social sophistication.

The contrast between Goober-in-the-garage and Goober-at-Floyd's is one of the sharpest demonstrations of how room context activates different behavioral layers in a character.
